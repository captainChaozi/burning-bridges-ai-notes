# What uses a Burning Bridges AI generation (and what does not)

A reference table for [Burning Bridges AI](https://burningbridges.dev/). One "video" in a pack = one new generation.

## Packs

| Pack | Price | Per video | Validity |
|---|---|---|---|
| 1 video | $5.99 | $5.99 | 365 days from payment |
| 3 videos | $14.99 | $5.00 | 365 days |
| 10 videos | $44.99 | $4.50 | 365 days |

All packs are one-time payments with no automatic renewal, and all use the same fixed effect and quality (10 s, 720p, silent MP4). Source: [pricing](https://burningbridges.dev/pricing).

## Actions

| Action | Uses a generation? |
|---|---|
| Watching the sample / examples | No |
| Choosing or replacing a photo | No |
| Signing in | No |
| Buying a pack | No (payment adds generations; it does not start a video) |
| Pressing Create / submitting | **Yes** |
| A new take with the same photo | **Yes** |
| Refreshing while a task runs | No (restores the saved task) |
| Downloading a finished video | No |
| Confirmed failed or cancelled task | Generation returned |
| Approved quality review (within 7 days) | Generation restored once; no automatic new video, no cash refund |

## Notes

- A task still being checked may not be ready for settlement; follow it rather than resubmitting.
- Cash refunds are a separate process: [refund policy](https://burningbridges.dev/refund-policy).
- Workflow details: [user guide](https://burningbridges.dev/user-guide).
