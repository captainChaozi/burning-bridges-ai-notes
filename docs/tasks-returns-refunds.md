# Burning Bridges AI: tasks, returns, reviews and refunds

Reference notes for [Burning Bridges AI](https://burningbridges.dev/), an independent tool that turns one adult portrait into a 10-second chandelier party video (720p, 16:9 or 9:16, silent MP4). This page lists what happens to a paid generation in each situation. Source pages: [user guide](https://burningbridges.dev/user-guide), [refund policy](https://burningbridges.dev/refund-policy), [pricing](https://burningbridges.dev/pricing).

## Task outcomes

| Situation | What happens | What you do |
|---|---|---|
| Task still pending or being checked | Nothing yet; a long wait is not a failure | Keep following the same task; refreshing restores it |
| Confirmed failed or cancelled | The generation is returned through settlement | Check Available videos; contact support with the task ID if missing |
| Completed, but lead unrecognisable, a gesture missing, or file unplayable | Eligible for a quality review within 7 days | Send task ID, timestamp and description |
| Completed, small details differ | Normal variation | Review before sharing; a new take is a new charged task |
| Completed, you just want another look | Not a defect | Submit a new task |

## Money

- Packs are one-time purchases: 1 video $5.99, 3 for $14.99, 10 for $44.99. No subscription, no automatic renewal.
- Generations are valid for 365 days from payment confirmation. Expiry is separate from a technical failure.
- Cash refunds are reviewed case by case. Duplicate charges, unauthorised payments or generations not delivered after confirmed payment should be reported promptly.
- An approved quality review restores one generation; it is not a cash refund.

## Do not

- Create several new tasks while the first is unresolved.
- Pay again only because an order looks pending.
- Send passwords, security codes or full card details to support.
