# Photo input and output format reference

Quick reference for [Burning Bridges AI](https://burningbridges.dev/), taken from the site's guides (last updated 2026-10-17).

## Input photo

| Rule | Value |
|---|---|
| Formats | JPG, PNG, WebP |
| Max size | 10 MB |
| Minimum dimensions | 128 × 128 px |
| Subject | One consenting adult |
| Avoid | Group photos, sunglasses, masks, heavy blur, hands across the face |
| Not supported | Children, pets, unauthorised public figures |

## Output

| Item | Value |
|---|---|
| Model | Wan 2.7 Video Edit |
| Length | 10 seconds |
| Resolution | 720p |
| Formats | 16:9 landscape or 9:16 portrait |
| Audio | None (add your own licensed music) |

20-second clips and 1080p are not available in this recipe. The 9:16 format uses its own reframed reference with soft background bands above and below the performer.

## The three gestures

1. Wave – greeting the camera beneath the chandeliers
2. Toast – lifting a silver cup
3. Lookout – a hand shading the eyes while searching the room
